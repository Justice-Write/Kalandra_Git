# Kalandra 0.1.0-pre.2 — desktop test release

This is a free unsigned test release, not commercial or provider acceptance.
It retains the published overlay source and fixes the release boundary:

- Source and code-update ZIPs use tracked runtime files only, with no `data_engine`,
  personal exports/backups, local configurations, key stores, virtual environments,
  private handoffs, or operational folders.
- No database is discovered or bundled from this computer. An optional reference
  dataset would require its own provenance, privacy and licensing review.
- A setup-wizard binary is opt-in and compiled afresh by the existing Windows CI.
  Local source ZIPs use the documented PowerShell fallback instead of stale binaries.
- Supported Windows/Python 3.12 installs use the audited lock: certifi 2026.10.19
  and filelock 4.2.1; the full lock has zero current pip-audit findings.
- Version-specific CI release tags record their exact source instead of rewriting
  the historical rolling installer tag.

## Desktop use and user data

Extract the source package into a new per-user application folder. Install the
Python 3.12 requirements into its own `.venv`, then use the documented per-user
`installer/Make-Shortcut.ps1` registration. It prefers the app-local interpreter
and preserves a pre-existing shortcut before updating it. No administrator rights
or system service is required.

For isolated first launch, register with `-SafeStartup` or run
`python main.py --safe-startup`. This suppresses automatic source/account sync,
game/index checks, clipboard watching and game/death-log watching. It does not
disable user-triggered network features or act as a firewall. No provider calls,
microphone use, capture or model downloads are part of release verification.

Local runtime data remains under the app's `data_engine` area (plus explicitly
chosen user directories); keys stay in the OS keychain. Data is not included in
the ZIP or overwritten by the code-only update. Back up a working install and
runtime data before replacing it. No automatic user-data migration is claimed.

## Verified scope

The baseline stress suite passes 293 checks. The 21 existing/new check suites
pass, including five native Qt widget tests and eight archive-boundary tests;
two additional safe-startup tests pass. The synthetic economy fixture now uses
recent dates plus a deliberately expired point, preserving rolling-window
coverage. Both changed PowerShell installer scripts parse. The original
development environment was not modified; the two patched dependencies were
validated in an isolated overlay.

Physical window placement, game interaction, optional tools, live provider/GGG
OAuth behavior, commercial licensing, signing and unresolved retention/local-model
choices remain separate gates. Exact source, artifact hash and installed-state
readback belong to the release receipt and current root handoff.
